# Shared Instruction Priority Tags

Used by all web3-* skills and `_shared/*.md` files. When you see one of these tags wrapping a block of text, treat the content at the indicated priority:

1. **`<NEVER>`** — Absolute prohibition. Violation may cause irreversible fund loss or break a fundamental safety invariant.
2. **`<MUST>`** — Mandatory step. Skipping breaks functionality or safety.
3. **`<SHOULD>`** — Best practice. Deviation acceptable with stated reason.
